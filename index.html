Окислительно-восстановительные реакции

Полная теория: марганец, хром, окислители, восстановители и алгоритм решения

1. Что такое ОВР

ОпределениеОсновы

ОВР — окислительно-восстановительная реакция — реакция, в которой атомы одних элементов отдают электроны, а атомы других — принимают. Из-за этого меняются степени окисления.

Не ОВР: Ba(OH)₂ + H₂SO₄ → BaSO₄↓ + H₂O. Степени окисления не меняются.

ОВР: Fe⁺²O + HN⁺⁵O₃ → Fe⁺³(NO₃)₃ + N⁺⁴O₂ + H₂O. Железо повысило СО, азот понизил.

ПонятияОкислитель и восстановитель

Окислитель
принимает электроны, понижает СО, восстанавливается
Восстановитель
отдаёт электроны, повышает СО, окисляется

процесс отдачи электронов (восстановителем)
Восстановление
процесс принятия электронов (окислителем)
Главное правило: число отданных электронов = число принятых. Это баланс.

2. Степени окисления

ОпределениеЧто такое СО

Степень окисления — гипотетический заряд атома, если бы все связи в молекуле стали ионными.

Правило суммы: сумма всех СО в молекуле = 0. В ионе — заряду иона.

Пример K₂SO₄: 2·(+1) + S + 4·(−2) = 0 → S = +6.

4. Соединения марганца

ТеорияСтепени окисления марганца

Марганец Mn — d-элемент VIIB группы. Проявляет степени окисления: 0, +2, +3, +4, +6, +7.

Mn⁰
простое вещество Mn
Mn⁺²
MnSO₄, MnCl₂, Mn(NO₃)₂ — соли марганца(II). Бесцветные или бледно-розовые растворы
Mn⁺³
Mn₂O₃ — неустойчив, промежуточный
Mn⁺⁴
MnO₂ — оксид марганца(IV). Бурый осадок, амфотерный
Mn⁺⁶
K₂MnO₄ — манганат калия. Зелёный раствор
Mn⁺⁷
KMnO₄, HMnO₄ — перманганат. Фиолетовый раствор
Ключевая логика: в ОВР KMnO₄ (Mn⁺⁷) восстанавливается. Куда — зависит от среды. Mn⁺² в свою очередь может окисляться до MnO₂ или MnO₄⁻.

Главное правилоKMnO₄ в трёх средах

Перманганат калия KMnO₄ — сильнейший окислитель. Что получится, зависит от среды. Это правило работает всегда.

Кислая среда (H₂SO₄)
Mn⁺⁷ → Mn⁺². Продукт: MnSO₄ или Mn(NO₃)₂. Бесцветный раствор
Нейтральная среда (H₂O)
Mn⁺⁷ → Mn⁺⁴. Продукт: MnO₂. Бурый осадок
Щелочная среда (KOH)
Mn⁺⁷ → Mn⁺⁶. Продукт: K₂MnO₄. Зелёный раствор
Обрати внимание: в кислой среде получается Mn⁺², потому что он устойчив в кислоте. В нейтральной — MnO₂, потому что он нерастворим. В щелочной — Mn⁺⁶, потому что он устойчив в щёлочи.

КислаяKMnO₄ в кислой среде

Обычно среда — H₂SO₄ (серная кислота). Mn⁺⁷ восстанавливается до Mn⁺².

2KMnO₄ + 5Na₂SO₃ + 3H₂SO₄ → 2MnSO₄ + 5Na₂SO₄ + K₂SO₄ + 3H₂O
Перманганат калия + сульфит натрия + серная кислота = сульфат марганца(II) + сульфат натрия + сульфат калия + вода. Восстановитель — Na₂SO₃ (S⁺⁴ → S⁺⁶). Окислитель — KMnO₄ (Mn⁺⁷ → Mn⁺²).

Электронный баланс

Mn⁺⁷ + 5e⁻ → Mn⁺² | ×2 S⁺⁴ − 2e⁻ → S⁺⁶ | ×5 НОК = 10
Марганец принимает 5 электронов, сера отдаёт 2. Умножаем на 2 и 5, чтобы уравнять.

НейтральнаяKMnO₄ в нейтральной среде

Среда — вода. Mn⁺⁷ восстанавливается до Mn⁺⁴, образуется бурый осадок MnO₂.

2KMnO₄ + 3Na₂SO₃ + H₂O → 2MnO₂↓ + 3Na₂SO₄ + 2KOH
Перманганат калия + сульфит натрия + вода = оксид марганца(IV) (бурый осадок) + сульфат натрия + гидроксид калия. Mn⁺⁷ → Mn⁺⁴.

Электронный баланс

Mn⁺⁷ + 3e⁻ → Mn⁺⁴ | ×2 S⁺⁴ − 2e⁻ → S⁺⁶ | ×3 НОК = 6
Марганец принимает 3 электрона, сера отдаёт 2. НОК(3,2) = 6.
Важно: в нейтральной среде образуется KOH — щёлочь. Именно поэтому после реакции среда становится щелочной. Это нужно учитывать при расстановке коэффициентов.

ЩелочнаяKMnO₄ в щелочной среде

Среда — KOH или NaOH. Mn⁺⁷ восстанавливается до Mn⁺⁶, образуется зелёный манганат.

2KMnO₄ + Na₂SO₃ + 2KOH → 2K₂MnO₄ + Na₂SO₄ + H₂O
Перманганат калия + сульфит натрия + гидроксид калия = манганат калия (зелёный) + сульфат натрия + вода. Mn⁺⁷ → Mn⁺⁶.

Электронный баланс

Mn⁺⁷ + 1e⁻ → Mn⁺⁶ | ×2 S⁺⁴ − 2e⁻ → S⁺⁶ | ×1 НОК = 2
Марганец принимает 1 электрон, сера отдаёт 2. Умножаем на 2 и 1.

Как понятьКуда пойдёт Mn⁺⁷

Если в задании есть KMnO₄ — первым делом смотри, что в среде:

  1. Есть H₂SO₄, HNO₃, H⁺ → кислая среда → продукт Mn⁺² (MnSO₄/Mn(NO₃)₂).
  2. Есть H₂O, нет кислоты и щёлочи → нейтральная среда → продукт MnO₂↓.
  3. Есть KOH, NaOH, OH⁻ → щелочная среда → продукт K₂MnO₄.
Ловушка: если в задании даны только KMnO₄ и восстановитель без среды — среда нейтральная (вода). Тогда продукт — MnO₂.

Как понятьОкисление Mn⁺²

Mn⁺² — сам может быть восстановителем. Его окисляют сильные окислители (PbO₂, NaBiO₃, HNO₃(конц.)).

2MnSO₄ + 5PbO₂ + 6HNO₃ → 2HMnO₄ + 5Pb(NO₃)₂ + 2H₂SO₄ + 2H₂O
Сульфат марганца(II) + оксид свинца(IV) + азотная кислота = марганцевая кислота + нитрат свинца(II) + серная кислота + вода. Mn⁺² → Mn⁺⁷.
В школьной программе окисление Mn⁺² встречается редко. В основном KMnO₄ — это окислитель.

5. Соединения хрома

ТеорияСтепени окисления хрома

Хром Cr — d-элемент VIB группы. Проявляет степени окисления: 0, +2, +3, +6.

Cr⁰
простое вещество Cr
Cr⁺²
CrO, CrCl₂ — неустойчивы, легко окисляются до Cr⁺³
Cr⁺³
Cr₂O₃, Cr(OH)₃, CrCl₃, Cr₂(SO₄)₃ — зелёные или фиолетовые соединения. Амфотерные
Cr⁺⁶
CrO₃, K₂CrO₄ (жёлтый), K₂Cr₂O₇ (оранжевый) — сильные окислители
Ключевая логика: Cr⁺⁶ — сильный окислитель, восстанавливается до Cr⁺³. Cr⁺³ может быть и окислителем (редко), и восстановителем (окисляется до Cr⁺⁶ в щелочной среде с сильным окислителем).

ЦветаКак узнать соединение хрома

Соединение СО хрома Цвет
Cr⁰ (металл) 0 Серебристо-серый
CrCl₂, CrSO₄ +2 Голубой (неустойчив)
Cr₂O₃, Cr(OH)₃ +3 Зелёный (серо-зелёный)
Cr₂(SO₄)₃, CrCl₃ +3 Фиолетовый или зелёный (зависит от гидратации)
K₂CrO₄ +6 Жёлтый (хромат)
K₂Cr₂O₇ +6 Оранжевый (дихромат)
CrO₃ +6 Тёмно-красные кристаллы
Важно: жёлтый K₂CrO₄ и оранжевый K₂Cr₂O₇ — это разные формы одного и того же. В щелочной среде преобладает хромат (жёлтый), в кислой — дихромат (оранжевый).

КислаяK₂Cr₂O₇ в кислой среде

В кислой среде Cr⁺⁶ восстанавливается до Cr⁺³. Обычно среда — H₂SO₄.

K₂Cr₂O₇ + 3Na₂SO₃ + 4H₂SO₄ → Cr₂(SO₄)₃ + 3Na₂SO₄ + K₂SO₄ + 4H₂O
Дихромат калия + сульфит натрия + серная кислота = сульфат хрома(III) (зелёный) + сульфат натрия + сульфат калия + вода. Cr⁺⁶ → Cr⁺³.

Электронный баланс

2Cr⁺⁶ + 6e⁻ → 2Cr⁺³ | ×1 S⁺⁴ − 2e⁻ → S⁺⁶ | ×3 НОК = 6
Два атома хрома принимают 6 электронов (по 3 на каждый), сера отдаёт 2. НОК(6,2) = 6.

Другой пример — с сероводородом

K₂Cr₂O₇ + 3H₂S + 4H₂SO₄ → Cr₂(SO₄)₃ + 3S↓ + K₂SO₄ + 7H₂O
Дихромат калия + сероводород + серная кислота = сульфат хрома(III) + сера (осадок) + сульфат калия + вода. S⁻² → S⁰ (отдаёт 2e⁻).

НейтральнаяK₂Cr₂O₇ в нейтральной или щелочной среде

Cr⁺⁶ восстанавливается до Cr⁺³, но продукт другой — Cr(OH)₃ (серо-зелёный осадок).

K₂Cr₂O₇ + 3Na₂S + 7H₂O → 2Cr(OH)₃↓ + 3S↓ + 6NaOH + 2KOH
Дихромат калия + сульфид натрия + вода = гидроксид хрома(III) (осадок) + сера (осадок) + гидроксид натрия + гидроксид калия. Cr⁺⁶ → Cr⁺³.
В нейтральной среде получается именно Cr(OH)₃ — нерастворимое основание, а не соль. Это отличает восстановление хрома от марганца.

ОбратноОкисление Cr⁺³ до Cr⁺⁶

Cr⁺³ — восстановитель. Его окисляют в щелочной среде сильными окислителями (H₂O₂, KMnO₄, Br₂, Na₂O₂).

2CrCl₃ + 3H₂O₂ + 10KOH → 2K₂CrO₄ + 6KCl + 8H₂O
Хлорид хрома(III) + пероксид водорода + гидроксид калия = хромат калия (жёлтый) + хлорид калия + вода. Cr⁺³ → Cr⁺⁶. H₂O₂ здесь окислитель.
2Cr₂(SO₄)₃ + 3Br₂ + 16KOH → 4K₂CrO₄ + 6KBr + 6K₂SO₄ + 8H₂O
Сульфат хрома(III) + бром + гидроксид калия = хромат калия + бромид калия + сульфат калия + вода. Cr⁺³ → Cr⁺⁶. Br₂ — окислитель.
Важно: окисление Cr⁺³ до Cr⁺⁶ идёт только в щелочной среде. В кислой среде Cr³⁺ устойчив и не окисляется.

СравнениеМарганец vs Хром

Среда KMnO₄ (Mn⁺⁷) K₂Cr₂O₇ (Cr⁺⁶)
Кислая (H⁺) Mn⁺⁷ → Mn⁺² (бесцв.) Cr⁺⁶ → Cr⁺³ (зелёный)
Нейтральная (H₂O) Mn⁺⁷ → Mn⁺⁴ (MnO₂↓ бурый) Cr⁺⁶ → Cr⁺³ (Cr(OH)₃↓ серо-зелёный)
Щелочная (OH⁻) Mn⁺⁷ → Mn⁺⁶ (K₂MnO₄ зелёный) Cr⁺⁶ → Cr⁺³ (Cr(OH)₃↓)
Логика: марганец меняет продукт при смене среды (Mn⁺² / MnO₂ / K₂MnO₄). Хром всегда восстанавливается до Cr⁺³, но продукт зависит от среды (соль или гидроксид).

6. Как понять, что получится

МетодПошаговая логика

  1. Определи степени окисления всех элементов в реагентах.
  2. Найди элементы, которые меняют СО. Это будут окислитель и восстановитель.
  3. Посмотри, кто окислитель, кто восстановитель. Окислитель — понижает СО. Восстановитель — повышает.
  4. Определи среду: кислая, нейтральная, щелочная.
  5. По среде определи продукт окислителя (для KMnO₄ и K₂Cr₂O₇ — см. таблицы выше).
  6. По восстановителю определи продукт — до какой СО он окислится (обычно до максимальной устойчивой).
  7. Составь электронный баланс — определи, сколько e⁻ отдаёт восстановитель и сколько принимает окислитель.
  8. Уравняй через НОК, расставь коэффициенты.
  9. Проверь по H и O.

7. Алгоритм решения задания 29

Пошагово6 шагов

  1. Выпиши вещества из условия. Их обычно 5–6.
  2. Определи, кто окислитель, кто восстановитель. Используй таблицы из разделов 3–5.
  3. Выбери пару, которая может реагировать. Учитывай среду и совместимость.
  4. Составь электронный баланс. Найди, кто сколько e⁻ отдаёт и принимает. Уравняй через НОК.
  5. Расставь коэффициенты в уравнении. Проверь все атомы.
  6. Запиши ответ: уравнение + окислитель + восстановитель.

ПравилоКак выбрать пару веществ

Из списка веществ нужно выбрать два, которые прореагируют. Логика:

  • Окислитель + восстановитель.
  • Должны подходить по среде: например, если окислитель KMnO₄ и есть H₂SO₄ — среда кислая, продукт Mn⁺².
  • Не должны реагировать друг с другом раньше (например, две кислоты между собой).
Типичная ошибка: выбрать два окислителя или два восстановителя. Реакция между ними не пойдёт — оба хотят забрать или отдать электроны.

8. Примеры решения

Пример 1С марганцем

Дано: KMnO₄, Na₂SO₃, H₂SO₄, H₂O, KOH.

Шаг 1. Кто есть кто

KMnO₄ — окислитель (Mn⁺⁷). Na₂SO₃ — восстановитель (S⁺⁴). H₂SO₄ — кислая среда.

Шаг 2. Среда

Есть H₂SO₄ → среда кислая → Mn⁺⁷ → Mn⁺².

Шаг 3. Электронный баланс

Mn⁺⁷ + 5e⁻ → Mn⁺² | ×2 S⁺⁴ − 2e⁻ → S⁺⁶ | ×5 НОК(5,2) = 10

Шаг 4. Уравнение

2KMnO₄ + 5Na₂SO₃ + 3H₂SO₄ → 2MnSO₄ + 5Na₂SO₄ + K₂SO₄ + 3H₂O

Шаг 5. Ответ

Окислитель: KMnO₄ (Mn⁺⁷).
Восстановитель: Na₂SO₃ (S⁺⁴).

Пример 2С хромом

Дано: K₂Cr₂O₇, H₂S, H₂SO₄, H₂O, KOH.

Шаг 1. Кто есть кто

K₂Cr₂O₇ — окислитель (Cr⁺⁶). H₂S — восстановитель (S⁻²). H₂SO₄ — кислая среда.

Шаг 2. Среда

Есть H₂SO₄ → кислая → Cr⁺⁶ → Cr⁺³. S⁻² окисляется до S⁰ (H₂S — слабый восстановитель).

Шаг 3. Электронный баланс

2Cr⁺⁶ + 6e⁻ → 2Cr⁺³ | ×1 S⁻² − 2e⁻ → S⁰ | ×3 НОК(6,2) = 6

Шаг 4. Уравнение

K₂Cr₂O₇ + 3H₂S + 4H₂SO₄ → Cr₂(SO₄)₃ + 3S↓ + K₂SO₄ + 7H₂O

Шаг 5. Ответ

Окислитель: K₂Cr₂O₇ (Cr⁺⁶).
Восстановитель: H₂S (S⁻²).

Пример 3Со щелочной средой

Дано: KMnO₄, Na₂SO₃, KOH, H₂O, H₂SO₄.

Шаг 1. Кто есть кто

KMnO₄ — окислитель (Mn⁺⁷). Na₂SO₃ — восстановитель (S⁺⁴). KOH — щелочная среда.

Шаг 2. Среда

Есть KOH → щелочная → Mn⁺⁷ → Mn⁺⁶ (K₂MnO₄).

Шаг 3. Электронный баланс

Mn⁺⁷ + 1e⁻ → Mn⁺⁶ | ×2 S⁺⁴ − 2e⁻ → S⁺⁶ | ×1 НОК = 2

Шаг 4. Уравнение

2KMnO₄ + Na₂SO₃ + 2KOH → 2K₂MnO₄ + Na₂SO₄ + H₂O

Шаг 5. Ответ

Окислитель: KMnO₄ (Mn⁺⁷).
Восстановитель: Na₂SO₃ (S⁺⁴).

9. Ловушки ЕГЭ

Топ-10На чём теряют баллы

  • HNO₃ никогда не даёт H₂. Даже с активными металлами. Всегда NO₂ / NO / N₂O / N₂ / NH₄NO₃.
  • Пассивация Al, Cr, Fe. С конц. HNO₃ и H₂SO₄ без нагрева — не реагируют.
  • Fe + I₂ → FeI₂ (не FeI₃). Йод слабый окислитель, даёт только Fe²⁺.
  • 2Cu + I₂ → 2CuI (не CuI₂). Медь окисляется до Cu⁺.
  • KMnO₄ в разных средах даёт разные продукты. Кислая → Mn⁺². Нейтральная → MnO₂. Щелочная → K₂MnO₄.
  • K₂Cr₂O₇ всегда даёт Cr⁺³, но в нейтральной — Cr(OH)₃, а в кислой — соль.
  • Cr³⁺ окисляется до Cr⁶⁺ только в щелочной среде. В кислой — нет.
  • Продукты HNO₃ зависят от концентрации. Разб. + активный металл → N₂ / NH₄NO₃, а не NO₂.
  • Обязательно укажи окислитель и восстановитель в ответе. Без этого — минус балл.
  • Проверь баланс по H и O после расстановки коэффициентов.

ОтдельноСера и её соединения

  • H₂S + слабый окислитель → S⁰ (например, с Fe³⁺, I₂).
  • H₂S + сильный окислитель в кислоте → H₂SO₄ (например, с Cl₂ в избытке).
  • SO₂ + сильный окислитель → S⁺⁶ (сульфат).
  • SO₂ + H₂S → S⁰ (встреча двух СО серы).

ОтдельноАзот

  • NH₃ + O₂ без кат. → N₂ + H₂O.
  • NH₃ + O₂ с Pt → NO + H₂O.
  • HNO₂ — и окислитель, и восстановитель.
  • NH₄NO₂ → N₂ + H₂O (внутримолекулярная ОВР).

10. Визуальные признаки ОВР — что видно глазами

ВажноПочему это критично для ЕГЭ

В современном задании 29 часто просят выбрать реакцию с определённым визуальным признаком: «с изменением цвета раствора», «с выделением газа», «с выпадением осадка», «без видимых изменений».

Поэтому надо знать не только формулы, но и что видно глазами. На ОГЭ и старом ЕГЭ это не требовалось, а сейчас — обязательно.

Ловушка: если в условии сказано «с изменением цвета раствора, без осадка и газа» — реакция с образованием осадка или газа не подойдёт, даже если она правильная химически.

  2. Выпиши вещества из списка. Определи, кто окислитель, кто восстановитель.
  3. Посмотри на признак. Подходит ли реакция под условие?

11. Диспропорционирование

ОпределениеЧто это такое

Диспропорционирование — реакция, в которой один и тот же элемент является и окислителем, и восстановителем. Один атом этого элемента повышает СО, другой — понижает.

Когда происходит: когда элемент находится в промежуточной СО и может одновременно двигаться и вверх, и вниз.

Простой пример: Cl₂ + 2KOH → KCl + KClO + H₂O. Хлор был Cl⁰, стал Cl⁻¹ и Cl⁺¹.

Сера и фосфорСо щелочами

3S + 6KOH → 2K₂S + K₂SO₃ + 3H₂O
Сера + гидроксид калия = сульфид калия + сульфит калия + вода. S⁰ → S⁻² (понижение) и S⁰ → S⁺⁴ (повышение). Реакция идёт при кипячении.
4P + 3KOH + 3H₂O → PH₃↑ + 3KH₂PO₂
Фосфор + гидроксид калия + вода = фосфин (газ) + гипофосфит калия. P⁰ → P⁻³ (понижение) и P⁰ → P⁺¹ (повышение). При кипячении.
Запомни: идёт только при кипячении. При обычной температуре сера и фосфор со щелочами не реагируют.

ГалогеныС водой и щелочами

Без нагревания:

Cl₂ + H₂O → HCl + HClO
Хлор + вода = соляная кислота + хлорноватистая кислота. Cl⁰ → Cl⁻¹ и Cl⁰ → Cl⁺¹.
Cl₂ + 2KOH → KCl + KClO + H₂O
Хлор + гидроксид калия (холод) = хлорид калия + гипохлорит калия + вода.

При нагревании:

3Cl₂ + 6KOH → 5KCl + KClO₃ + 3H₂O
Хлор + гидроксид калия (нагрев) = хлорид калия + хлорат калия + вода. В горячей щёлочи хлор окисляется сразу до +5.
Ловушка: фтор со щелочами не диспропорционирует — он слишком сильный окислитель. F₂ + 2KOH → 2KF + O₂ + H₂O (окисляет кислород щёлочи, а не себя).

АзотNO₂ и соли

2NO₂ + H₂O → HNO₂ + HNO₃
Оксид азота(IV) + вода = азотистая кислота + азотная кислота. N⁺⁴ → N⁺³ и N⁺⁴ → N⁺⁵.
2NO₂ + 2KOH → KNO₂ + KNO₃ + H₂O
Оксид азота(IV) + гидроксид калия = нитрит калия + нитрат калия + вода.
4KClO₃ → 3KClO₄ + KCl
Хлорат калия при нагревании = перхлорат калия + хлорид калия. Cl⁺⁵ → Cl⁺⁷ и Cl⁺⁵ → Cl⁻¹.

12. Повышение СО хрома и марганца

ТеорияОбратный процесс

Мы разбирали, как KMnO₄ и K₂Cr₂O₇ окисляют другие вещества и сами восстанавливаются. Но бывает и наоборот: Cr³⁺ и Mn²⁺ могут быть восстановителями и окисляться до высших СО.

Ключевая логика: окислить Cr³⁺ до Cr⁶⁺ можно только в щелочной среде очень сильными окислителями (H₂O₂, Br₂, Na₂O₂, KMnO₄, хлорсодержащие соли). В кислой среде Cr³⁺ устойчив и не окисляется.

Cr³⁺ → Cr⁶⁺В щелочной среде

2CrCl₃ + 3H₂O₂ + 10KOH → 2K₂CrO₄ + 6KCl + 8H₂O
Хлорид хрома(III) + пероксид водорода + гидроксид калия = хромат калия (жёлтый) + хлорид калия + вода. Cr⁺³ → Cr⁺⁶, H₂O₂ — окислитель (O⁻¹ → O⁻²).
2Cr₂(SO₄)₃ + 3Br₂ + 16KOH → 4K₂CrO₄ + 6KBr + 6K₂SO₄ + 8H₂O
Сульфат хрома(III) + бром + гидроксид калия = хромат калия + бромид калия + сульфат калия + вода. Cr⁺³ → Cr⁺⁶, Br₂ — окислитель (Br⁰ → Br⁻¹).
2Cr(OH)₃ + 3Na₂O₂ → 2Na₂CrO₄ + 2NaOH + 2H₂O
Гидроксид хрома(III) + пероксид натрия = хромат натрия + гидроксид натрия + вода. Cr⁺³ → Cr⁺⁶.

В кислой среде: Cr³⁺ не окисляется. Остаётся Cr³⁺ (в виде Cr₂(SO₄)₃, CrCl₃ и т.д.).

Ловушка: если в задании среда кислая — не пытайся окислить Cr³⁺. Окисление возможно только в щёлочи.

Mn²⁺ → Mn⁷⁺Очень сильные окислители

Mn²⁺ — восстановитель. Его окисляют PbO₂, NaBiO₃, концентрированная HNO₃.

2MnSO₄ + 5PbO₂ + 6HNO₃ → 2HMnO₄ + 5Pb(NO₃)₂ + 2H₂SO₄ + 2H₂O
Сульфат марганца(II) + оксид свинца(IV) + азотная кислота = марганцевая кислота + нитрат свинца(II) + серная кислота + вода. Mn⁺² → Mn⁺⁷. PbO₂ — окислитель.
В школьной программе окисление Mn²⁺ встречается редко. Запомни главное: KMnO₄ — это окислитель, а не восстановитель. Восстановителем он бывает только в очень специфических случаях.

13. Активность металлов и неметаллов

Ряд напряженийЭлектрохимический ряд металлов

Чем левее металл в ряду — тем он активнее и тем сильнее как восстановитель.

Металлы левее H₂ вытесняют водород из кислот-неокислителей (HCl, H₂SO₄ разб.). Металлы правее H₂ с такими кислотами не реагируют.

14. Особые случаи окислителей и восстановителей

Правило 1Кислородсодержащие соли и кислоты хлора

В реакциях с восстановителями всегда переходят в хлориды (Cl⁻):

HClO, HClO₂, HClO₃, HClO₄
Cl⁺¹, Cl⁺³, Cl⁺⁵, Cl⁺⁷ → Cl⁻¹
KClO, KClO₃, KClO₄
→ KCl
Пример: KClO₃ + 6HCl → KCl + 3Cl₂↑ + 3H₂O. Хлор из +5 идёт в −1 (в KCl) и в 0 (в Cl₂).

Правило 2Встреча двух СО одного элемента

Если в реакции участвуют вещества, где один и тот же элемент имеет отрицательную и положительную СО — они «встречаются» в нулевой СО. Выделяется простое вещество.

2H₂S + SO₂ → 3S↓ + 2H₂O
Сероводород + оксид серы(IV) = сера (осадок) + вода. S⁻² и S⁺⁴ «встречаются» в S⁰.
5HCl + HClO₃ → 3Cl₂↑ + 3H₂O
Соляная кислота + хлорноватая кислота = хлор (газ) + вода. Cl⁻¹ и Cl⁺⁵ «встречаются» в Cl⁰.
NH₄NO₂ → N₂↑ + 2H₂O
Нитрит аммония (при нагревании) = азот (газ) + вода. N⁻³ и N⁺³ «встречаются» в N⁰. Внутримолекулярная ОВР.
NH₄NO₃ → N₂O↑ + 2H₂O
Нитрат аммония (при нагревании) = оксид азота(I) + вода. N⁻³ и N⁺⁵ → N⁺¹. Исключение: не N₂, а N₂O.

Правило 3Пероксид водорода — «оборотень»

Как окислитель (O⁻¹ → O⁻²)
Продукт — H₂O. С восстановителями: PbS, KI, Na₂SO₃
Как восстановитель (O⁻¹ → O⁰)
Продукт — O₂↑. С окислителями: KMnO₄, K₂Cr₂O₇
PbS + 4H₂O₂ → PbSO₄ + 4H₂O
Сульфид свинца + пероксид водорода = сульфат свинца + вода. H₂O₂ — окислитель, восстанавливается до воды.
2KMnO₄ + 5H₂O₂ + 3H₂SO₄ → 2MnSO₄ + K₂SO₄ + 5O₂↑ + 8H₂O
Перманганат калия + пероксид водорода + серная кислота = сульфат марганца(II) + сульфат калия + кислород (газ) + вода. H₂O₂ — восстановитель, окисляется до O₂.

15. Как проверить себя в задании 29

Чек-лист7 пунктов перед сдачей

  1. Есть ли в реакции и окислитель, и восстановитель? Если чего-то нет — реакция неверна.
  2. Правильно ли определены степени окисления? Проверь каждое вещество, особенно в органике.
  3. Учтены ли все атомы, меняющие СО? Особенно в K₂Cr₂O₇ — там 2 атома хрома.
  4. Соответствует ли продукт среде? KMnO₄ в кислой → Mn⁺², в нейтральной → MnO₂, в щелочной → K₂MnO₄.
  5. Не образуется ли в кислой среде оксид или основание? В кислоте продукты — только соли или кислоты.
  6. Не образуется ли в щелочной среде кислота? В щёлочи продукты — соли или основания.
  7. Сходится ли баланс по H и O? После расстановки коэффициентов посчитай атомы.

Топ-8Возможные ошибки

1. Потеря электронов у восстановителя. Например, забыли, что в K₂Cr₂O₇ 2 атома хрома, и учли только один.

2. Электроны «из космоса». В реакции есть только окислитель, но нет восстановителя (или наоборот).

3. Продукт не подходит среде. В кислой среде получили Cu(OH)₂ или NH₃ — так не бывает.

4. Образование металла или оксида в растворе. Они не могут получиться в водном растворе, если реагируют с водой.

5. Неправильные степени окисления в органике. Забыли учесть неуглеродное окружение.

6. Ошибки в пероксидах. Кислород в H₂O₂ и Na₂O₂ — это O⁻¹, а не O⁻².

7. Ошибки в двойных оксидах. В Fe₃O₄ и Pb₃O₄ металлы имеют две разные СО.

8. Не указан окислитель и восстановитель в ответе. За это снимают балл.

16. HNO₃ и H₂SO₄ с металлами — полная схема

ГлавноеHNO₃ — окислитель всегда

Азотная кислота HNO₃ — окислитель в любой концентрации. Никогда не выделяет H₂. Азот восстанавливается до разных продуктов — в зависимости от активности металла и концентрации кислоты.
Главная закономерность: чем активнее металл и чем меньше концентрация кислоты — тем сильнее восстанавливается азот (уходит дальше от +5).

Схема 1HNO₃(конц.) + Me

Работает для любых металлов — и активных, и неактивных. Исключения: пассивация Al, Cr, Fe; не реагируют Au, Pt.

Cu + 4HNO₃(конц.) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O
Медь + конц. азотная кислота = нитрат меди(II) + оксид азота(IV) (бурый газ) + вода. Азот N⁺⁵ → N⁺⁴.
Zn + 4HNO₃(конц.) → Zn(NO₃)₂ + 2NO₂↑ + 2H₂O
Цинк + конц. азотная кислота = нитрат цинка + оксид азота(IV) + вода. Даже с активным металлом в конц. кислоте получается NO₂.
Ag + 2HNO₃(конц.) → AgNO₃ + NO₂↑ + H₂O
Серебро + конц. азотная кислота = нитрат серебра + оксид азота(IV) + вода.
Вывод: HNO₃(конц.) + любой металл → NO₂. Это универсальное правило.

Схема 2HNO₃(разб.) + неактивный металл

Неактивные металлы — правее алюминия в ряду напряжений (Cu, Ag, Hg, Pt, Au).

3Cu + 8HNO₃(разб.) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O
Медь + разб. азотная кислота = нитрат меди(II) + оксид азота(II) (бесцветный газ) + вода. Азот N⁺⁵ → N⁺².
3Ag + 4HNO₃(разб.) → 3AgNO₃ + NO↑ + 2H₂O
Серебро + разб. азотная кислота = нитрат серебра + оксид азота(II) + вода.
Как узнать: металл стоит правее Al (Cu, Hg, Ag, Pt, Au) → продукт NO.

Схема 3HNO₃(разб.) + металл средней активности

Средние металлы — от Al до Fe включительно (Al, Mn, Zn, Cr, Fe).

4Zn + 10HNO₃(разб.) → 4Zn(NO₃)₂ + N₂O↑ + 5H₂O
Цинк + разб. азотная кислота = нитрат цинка + оксид азота(I) + вода. Азот N⁺⁵ → N⁺¹.
4Fe + 10HNO₃(разб.) → 4Fe(NO₃)₂ + N₂O↑ + 5H₂O
Железо (при недостатке кислоты) + разб. азотная кислота = нитрат железа(II) + оксид азота(I) + вода. Fe⁰ → Fe⁺².
Как узнать: металл от Al до Fe + разб. → продукт N₂O.

Схема 4HNO₃(разб.) + активный металл

Активные металлы — левее Mg включительно (Li, K, Ba, Sr, Ca, Na, Mg).

5Mg + 12HNO₃(разб.) → 5Mg(NO₃)₂ + N₂↑ + 6H₂O
Магний + разб. азотная кислота = нитрат магния + азот (газ) + вода. Азот N⁺⁵ → N⁰.
4Ca + 10HNO₃(разб.) → 4Ca(NO₃)₂ + N₂↑ + 5H₂O
Кальций + разб. азотная кислота = нитрат кальция + азот + вода.
Как узнать: металл левее Mg (или сам Mg) + разб. → продукт N₂.

Схема 5HNO₃(очень разб.) + активный металл

Если кислота очень разбавленная и металл активный — азот восстанавливается до NH₄NO₃ (или NH₃, который сразу образует соль).

4Mg + 10HNO₃(оч. разб.) → 4Mg(NO₃)₂ + NH₄NO₃ + 3H₂O
Магний + очень разб. азотная кислота = нитрат магния + нитрат аммония + вода. Азот N⁺⁵ → N⁻³.
4Zn + 10HNO₃(оч. разб.) → 4Zn(NO₃)₂ + NH₄NO₃ + 3H₂O
Цинк + очень разб. азотная кислота = нитрат цинка + нитрат аммония + вода.
Как узнать: активный металл + очень разб. → продукт NH₄NO₃.

17. Степени окисления в органических веществах

Главное правилоЧто учитывать

В органических веществах нас интересуют степени окисления только тех атомов углерода, которые меняют своё окружение в процессе ОВР. Остальные атомы углерода не рассматриваем.
Как считать: общий заряд атома углерода и его неуглеродного окружения принимается за 0. Значит, СО углерода = сумма зарядов всех соседних атомов (кроме других углеродов).

МетодКак считать СО углерода

  1. Найди атом углерода, который меняет окружение в реакции.
  2. Посмотри, с чем он связан: с C, H, O, N, Hal?
  3. Присвой заряды соседям:
    • C–C — связи с углеродом считаем за 0 (или ±0)
    • C–H — водород даёт +1
    • C–O — кислород даёт −2
    • C–N — азот даёт −3
    • C–Hal — галоген даёт −1
  4. Сложи все заряды от соседей — это и будет СО углерода.
Проверка: сумма СО всех атомов в молекуле = 0.

Пример 1Метан CH₄

Углерод связан с 4 атомами водорода.

CH₄: C–H × 4 → C = 4·(−1) = −4
СО углерода в метане = −4. Водород даёт +1, значит углерод «забирает» 4 электрона.

Пример 2Этан C₂H₆ (по атомам)

Рассмотрим один углерод: он связан с 1 C и 3 H.

C–C (0) + C–H × 3 (+1 каждый) → C = −3
СО каждого углерода в этане = −3. Проверка: 2·(−3) + 6·(+1) = −6 + 6 = 0.

Пример 32-метилбутен-2

Формула: CH₃–C(CH₃)=CH–CH₃. Нас интересует углерод при двойной связи (в середине).

Атом C при C=C связан с: 2 C (0) + 0 H + 1 C-сосед через двойную связь (0) = 0 Но у него 1 метильная группа и 1 C-сосед. Итого: 2 C-связи = 0, 1 метил = 0
СО центрального углерода при C=C в 2-метилбутене-2 = 0. Он связан только с углеродами, а углерод-углеродные связи дают 0.
Если бы при C=C был H: например в бутене-1 CH₂=CH–CH₂–CH₃. Первый углерод связан с 1 C (0) + 2 H (+1 каждый) = −2.

Пример 4Ацетон CH₃–CO–CH₃

Центральный углерод связан с кислородом двойной связью и с двумя метильными группами.

C=O: 2 связи с O (−2 каждый) = −4 C–C × 2: по 0 = 0 Итого: C = −4 + 0 = +2
СО центрального углерода в ацетоне = +2. Кислород «оттягивает» на себя 4 электрона от углерода.
Проверка: CH₃ (C = −3) × 2 + C (центральный, +2) + O (−2) = −6 + 2 − 2 = −6. Ошибка? Нет! Считаем отдельно: 2·(−3) + (+2) + (−2) = −6 + 0 = −6. В метиле −3, потому что C связан с 3 H (+1) и 1 C (0).
Значит: −6 + 2 + (−2) = −6. Не сходится. На самом деле: 2·(−3) + (+2) + (−2) = −6 + 0 = −6. Хм, сумма СО не даёт 0 — это потому что мы считаем не по формальным СО всех атомов, а по локальному методу. Сумма формальных СО: C(1) = −3, C(2) = −3, C(центральный) = +2, O = −2, H × 6 = +6. Итого: −3 −3 +2 −2 +6 = 0. Всё сходится.

Пример 5Уксусная кислота CH₃–COOH

Нас интересует углерод карбоксильной группы.

C в –COOH: C=O: 2 связи с O (−2 каждая) = −4 C–O–H: 1 связь с O (−2) = −2 C–C: 1 связь с C (0) = 0 Итого: C = −4 − 2 + 0 = +3
СО углерода карбоксильной группы в уксусной кислоте = +3. Три связи с кислородом.

Углерод метильной группы

C в CH₃: C–H × 3 (+1) = +3 C–C (0) = 0 Итого: C = −3
СО углерода метила = −3.

В ОВР органика обычно восстановитель — окисляется (СО углерода растёт). Окислитель — KMnO₄, K₂Cr₂O₇ и т.д.

• CH₃–CH= → CH₃COOH (уксусная кислота)
• =CH₂ → CO₂ (углекислый газ)
• –CH= → –COOH (карбоновая кислота)

Мягкое окислениеАлкены → диолы

При мягком окислении (KMnO₄, 0 °C, водный раствор) двойная связь не рвётся, образуется диол.

3CH₂=CH₂ + 2KMnO₄ + 4H₂O → 3HO-CH₂-CH₂-OH + 2MnO₂↓ + 2KOH
Этилен + перманганат калия + вода = этиленгликоль (этандиол-1,2) + оксид марганца(IV) (осадок) + гидроксид калия. Углерод в =CH₂: было −2, стало −1 (в –CH₂OH). Повышение на 1.
3CH₃-CH=CH₂ + 2KMnO₄ + 4H₂O → 3CH₃-CH(OH)-CH₂-OH + 2MnO₂↓ + 2KOH
Пропен + перманганат калия + вода = пропандиол-1,2 + оксид марганца(IV) + гидроксид калия.

18. Практика: 16 заданий с решениями

Задание 1Расстановка СО

Условие: Расставьте степени окисления в веществах:

  • KMnO₄
  • K₂Cr₂O₇
  • H₂O₂
  • Fe₃O₄
  • Na₂O₂
Решение:
KMnO₄: K⁺¹ + Mnˣ + 4·O⁻² = 0 → 1 + x − 8 = 0 → Mn⁺⁷
K₂Cr₂O₇: 2·(+1) + 2x + 7·(−2) = 0 → 2 + 2x − 14 = 0 → Cr⁺⁶
H₂O₂: 2·(+1) + 2x = 0 → O⁻¹
Fe₃O₄: 3x + 4·(−2) = 0 → 3x = 8 → Fe = +8/3 (смешанный оксид)
Na₂O₂: 2·(+1) + 2x = 0 → O⁻¹

Задание 2СО углерода в органике

Условие: Определите СО углерода в 2-метилбутене-2, ацетоне и уксусной кислоте.

Решение:
2-метилбутен-2 (CH₃–C(CH₃)=CH–CH₃): центральный углерод при C=C связан с 2 C и 1 C через двойную связь → СО = 0.
Ацетон (CH₃–CO–CH₃): центральный углерод связан с O двойной связью и 2 C → СО = +2.
Уксусная кислота (CH₃–COOH): углерод в –COOH связан с O (двойная) и O–H → СО = +3.

Задание 3Коэффициент с дихроматом

Условие: K₂Cr₂O₇ + H₂S + H₂SO₄ → Cr₂(SO₄)₃ + S↓ + K₂SO₄ + H₂O. Какой коэффициент перед дихроматом?

Решение:
2Cr⁺⁶ + 6e⁻ → 2Cr⁺³ | ×1
S⁻² − 2e⁻ → S⁰ | ×3
НОК(6, 2) = 6. Перед K₂Cr₂O₇ — коэффициент 1.

Задание 4Коэффициент с магнием

Условие: Mg + HNO₃(разб.) → Mg(NO₃)₂ + N₂ + H₂O. Какой коэффициент перед Mg?

Решение:
Mg⁰ − 2e⁻ → Mg⁺² | ×5
2N⁺⁵ + 10e⁻ → N₂⁰ | ×1
Перед Mg — 5.

Задание 5Среда реакции

Условие: KMnO₄ + K₂SO₃ + X → K₂MnO₄ + K₂SO₄ + ... Что такое X — кислота, вода или щёлочь?

Решение:
Продукт — K₂MnO₄ (Mn⁺⁶). Это значит, что среда щелочная. X = KOH.
Уравнение: 2KMnO₄ + K₂SO₃ + 2KOH → 2K₂MnO₄ + K₂SO₄ + H₂O.

Задание 6Вода в реакции

Условие: Zn + KOH + H₂O → K₂[Zn(OH)₄] + H₂↑. В какой стороне вода?

Решение:
Zn⁰ − 2e⁻ → Zn⁺² | ×1
2H⁺¹ + 2e⁻ → H₂⁰ | ×1
Уравнение: Zn + 2KOH + 2H₂O → K₂[Zn(OH)₄] + H₂↑. Вода — в левой части.

Задание 7Мягкое и жёсткое окисление

Условие: Допишите реакции окисления пропена:

  • хол. раствор KMnO₄ (мягкое)
  • KMnO₄ + H₂SO₄, t° (жёсткое)
Решение:
Мягкое: 3CH₃-CH=CH₂ + 2KMnO₄ + 4H₂O → 3CH₃-CH(OH)-CH₂-OH + 2MnO₂↓ + 2KOH.
Жёсткое: CH₃-CH=CH₂ + 2KMnO₄ + 3H₂SO₄ → CH₃COOH + CO₂↑ + K₂SO₄ + 2MnSO₄ + 4H₂O.

Задание 8Продукты по силе окислителя

Условие: Допишите: FeS + HNO₃(конц.) → ...

Решение:
HNO₃(конц.) — сильный окислитель. S⁻² окислится до S⁺⁶ (сульфат), Fe²⁺ → Fe³⁺.
FeS + 12HNO₃(конц.) → Fe(NO₃)₃ + H₂SO₄ + 9NO₂↑ + 5H₂O.

Задание 9До какой СО окислится сера

Условие: Допишите: H₂S + K₂Cr₂O₇ + H₂SO₄ → ...

Решение:
K₂Cr₂O₇ — сильный окислитель в кислой среде. Но H₂S — слабый восстановитель, окислится только до S⁰.
K₂Cr₂O₇ + 3H₂S + 4H₂SO₄ → Cr₂(SO₄)₃ + 3S↓ + K₂SO₄ + 7H₂O.

Задание 10Сколько продуктов

Условие: Допишите: MnO₂ + HCl(конц.) → ...

Решение:
Mn⁺⁴ + 2e⁻ → Mn⁺² | ×1
2Cl⁻ − 2e⁻ → Cl₂⁰ | ×1
MnO₂ + 4HCl(конц.) → MnCl₂ + Cl₂↑ + 2H₂O. Продуктов — три: соль, газ, вода.

Задание 11Кто окислитель, кто восстановитель

Условие: Cl₂ + I₂ + H₂O → ... Кто окислитель, кто восстановитель?

Решение:
Хлор электроотрицательнее йода (3,16 vs 2,66). Значит, Cl₂ — окислитель (Cl⁰ → Cl⁻¹), I₂ — восстановитель (I⁰ → I⁺⁵).
5Cl₂ + I₂ + 6H₂O → 2HIO₃ + 10HCl.

Задание 12Роль пероксида водорода

Условие: Определите роль H₂O₂ в реакциях:

  • H₂O₂ + KMnO₄ + H₂SO₄ → ...
  • H₂O₂ + KNO₂ → ...
  • H₂O₂ + PbS → ...
Решение:
1) KMnO₄ — сильный окислитель → H₂O₂ восстановитель (даёт O₂).
2KMnO₄ + 5H₂O₂ + 3H₂SO₄ → 2MnSO₄ + K₂SO₄ + 5O₂↑ + 8H₂O.
2) KNO₂ может быть и окислителем, и восстановителем, но нитрит чаще восстановитель → H₂O₂ окислитель (даёт H₂O).
H₂O₂ + KNO₂ → KNO₃ + H₂O.
3) PbS — восстановитель → H₂O₂ окислитель.
PbS + 4H₂O₂ → PbSO₄ + 4H₂O.

Задание 13Допишите и уравняйте

Условие: KI + KMnO₄ + H₂SO₄ → I₂ + MnSO₄ + ...

Решение:
2I⁻ − 2e⁻ → I₂ | ×5
Mn⁺⁷ + 5e⁻ → Mn⁺² | ×2
10KI + 2KMnO₄ + 8H₂SO₄ → 5I₂ + 2MnSO₄ + 6K₂SO₄ + 8H₂O.

Задание 14Двойной оксид

Условие: Fe₃O₄ + HNO₃(конц.) → ... Какой углерод (железо) окисляется?

Решение:
В Fe₃O₄ два типа железа: Fe⁺² и 2Fe⁺³. Окисляется только Fe⁺² → Fe⁺³.
Fe₃O₄ + 10HNO₃(конц.) → 3Fe(NO₃)₃ + NO₂↑ + 5H₂O.

Задание 15Надпероксид

Условие: KO₂ + ... → O₂ + ... Сколько электронов отдаёт надпероксид?

Решение:
В KO₂ кислород имеет СО −½ (надпероксид-ион O₂⁻).
Общий заряд O₂⁻ = −1. Значит, кислород может отдать только 1 электрон.
2KO₂ + 2H₂O → 2KOH + H₂O₂ + O₂↑.

Задание 16Ошибочные продукты

Условие: Найдите ошибки в реакциях:

  • KMnO₄ + H₂O₂ + H₂SO₄ → Mn(OH)₂ + O₂ + ...
  • K₂Cr₂O₇ + KOH → Cr(OH)₃ + ...
  • Zn + HNO₃(разб.) → Zn(NO₃)₂ + H₂↑
Решение:
1) В кислой среде не может получиться Mn(OH)₂ (основание). Правильно: MnSO₄.
2) В щелочной среде K₂Cr₂O₇ даёт Cr(OH)₃↓, но здесь нет восстановителя. Правильно: реакция не идёт (нет ОВР).
3) HNO₃ не даёт H₂! Правильно: Zn + HNO₃(разб.) → Zn(NO₃)₂ + N₂O + H₂O.
